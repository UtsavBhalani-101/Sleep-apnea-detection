## What we learned

after reading the Biswal paper where he used a mix of raw signals + spectrogram signals, I thought maybe the reason precision is stuck and model is performing bad might be related to bad representation of the apnea windows that is also found in the visual check.

So using spectrogram which shows frequencies over time which might help the model to differentiate better. 

That's what I hoped but nothing like this happened and the results stayed almost the same

The next thing I want to test is whether this is a label problem by checking Normal vs Hypopnea vs Apnea as currently the task is binary classification and all of them are labelled as apnea and based on the visual check some are same and some are very different so I think differentiating these 3 labels would surface that perhaps Normal and hypopnea are hard to differentiate
