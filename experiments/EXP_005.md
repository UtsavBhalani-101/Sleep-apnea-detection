- I was not expecting this behavior because apnea is complete or near complete halt of airflow so that should be differentiable enough, atleast visually
- The current pipeline is a binary classification - normal vs apnea but there is also a 3rd class - Hypopnea which is merged with apnea and I guess hypopnea is the one that's genuinely hard to distinguish  
2. I've also tested with a slightly differnt setup - SpO2 at 1Hz and rest at 10Hz and the result was almost the same

Resampling all the signals to 10 Hz is not really the problem as resampling each signal indiviudally doesn't really changed anything 

- This shows that there are 2 different kinds of "apnea" and I know it's true because when parsing respevt.txt file, there are 2 main classes - hypopnea and apnea (obstructive, central and mixed) and all are labelled as apnea in the current pipeline 

- I want to test out whether the performance is because of data or some methodological issue ? so I will do a sanity check - try to overfit the model and if it does then model is fine but if not then there is some fundamental issue with the current pipeline
